# Contributing to GCC GITAM Blr

Thanks for helping out! Anyone can contribute, whatever their experience.

1. Find or open an issue and comment that you'd like to work on it.
2. Fork the repository and create a branch (`feature/short-description`).
3. Make your change, keeping commits small and messages clear.
4. Open a pull request that references the issue (`Closes #123`).
5. A maintainer will review it; please respond to feedback kindly and promptly.

New to Git? Ask in Discussions or at a club session. Nobody will mind.
