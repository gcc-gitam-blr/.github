# GitHub Community Club (GCC) — GITAM Bengaluru

A student-run community at GITAM Bengaluru for learning Git, GitHub, and open source by building things together.

## What we do
- **Workshops** – Git & GitHub basics, open-source contribution, GitHub Actions, and more
- **Projects** – club-run repositories that members build and maintain together
- **Events** – hack nights, study jams, and contribution sprints (e.g. Hacktoberfest)

## Get involved
- Browse our repositories and look for issues labelled `good first issue`
- Read [CONTRIBUTING](https://github.com/gcc-gitam-blr/.github/blob/main/CONTRIBUTING.md) before opening your first PR
- Questions or ideas? Open a Discussion, or email gccgitamblr@gmail.com

All skill levels are welcome. We follow our [Code of Conduct](https://github.com/gcc-gitam-blr/.github/blob/main/CODE_OF_CONDUCT.md).
